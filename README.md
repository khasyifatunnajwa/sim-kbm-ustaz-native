# SIM KBM Ustaz Native

Aplikasi Android native menggunakan Kotlin dan Jetpack Compose.

## Build APK

Build dilakukan melalui GitHub Actions.

1. Buka tab Actions pada repository GitHub.
2. Pilih workflow Build SIM KBM Ustaz Native APK.
3. Jalankan workflow atau tunggu build otomatis selesai.
4. Unduh artifact sim-kbm-ustaz-native-debug.

Fitur yang sudah tersedia:
- Data Kelas dan Data Murid
- Absensi Harian
- Jurnal KBM
- Jadwal Mengajar
- Nilai
- Rapor (rekap nilai per murid)
- Agenda
- Pengumuman
- Sikap (penilaian sikap murid)
- Tahun Ajaran & Semester
- Bank Soal
- Izin Mengajar
- Buku Saku
- Pengaturan
- Profil
- Sinkronisasi (antreean data lokal)

Login dan sinkronisasi Supabase belum diaktifkan. Data disimpan
secara lokal di perangkat.
